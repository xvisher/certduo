# Icons

Place the following PWA icons in this directory:
- `icon-192.png` — 192x192px app icon
- `icon-512.png` — 512x512px app icon
- `icon-maskable-512.png` — 512x512px maskable icon (safe area: centered 80% circle)

The icons should use the CertDuo brand:
- Background: #0078D4 (Microsoft Blue)
- Foreground: White "C" letter or CertDuo logomark
